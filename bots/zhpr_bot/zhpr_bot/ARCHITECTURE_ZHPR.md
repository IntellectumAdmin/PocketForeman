# 🧠 INTELLECTUM — Архитектура ЖПР-бота и структуры ГПР

Версия: 1.0 (черновик архитектуры)  
Автор: Ереке + Аян (INTELLECTUM)

---

## 1. Цель

Сделать так, чтобы:

- структура ГПР **автоматически** строилась из смет (PDF/Excel),
- пользователь, который загрузил смету (ПТО / прораб / руководитель), мог:
  - увидеть сгенерированную структуру,
  - при необходимости **отредактировать** её,
  - **утвердить** и сохранить,
- ЖПР-бот **никогда не зависел** от ручного редактирования `structure.txt` и использовал только утверждённую структуру.

---

## 2. Роли

### 🧱 Прораб / Руководитель участка
- Работает с **ЖПР-ботом** (PocketForeman).
- Ведёт дневной журнал производства работ.
- Может загружать смету, но **не обязан** её детально настраивать.

### 📐 ПТО / инженер-сметчик
- Основной пользователь для **работы со сметами и структурой ГПР**.
- Загружает смету (PDF/Excel).
- Проверяет и при необходимости корректирует структуру ГПР.
- Утверждает структуру → после этого её использует ЖПР-бот.

### 🧠 INTELLECTUM (платформа)
- Принимает файл сметы.
- Парсит смету (через модуль `analytics`).
- Строит и предлагает пользователю **черновую структуру ГПР**.
- Хранит **утверждённую** структуру и отдаёт её ЖПР-боту.

---

## 3. Основные компоненты

1. **Модуль Analytics**
   - `analytics/parsers/smeta_parser.py` — парсинг смет (PDF/Excel).
   - Строит список работ: код, название, раздел, объём, ресурсы и т.д.
   - На основе работ формирует дерево ГПР.

2. **Хранилище структуры ГПР**
   Варианты реализации (могут комбинироваться):
   - Notion-база `INTELLECTUM — ГПР структуры`
   - или JSON/БД на сервере.

   Минимальные поля:
   - `project_id` — идентификатор проекта (например, "Школа_65"),
   - `section_id` — внутренний ID раздела,
   - `parent_id` — ссылка на родителя,
   - `name` — название раздела,
   - `code` — код из сметы (если есть),
   - `order` — порядок сортировки.

3. **ЖПР-бот (`zhpr_bot`)**
   - Не знает про сметы и парсинг.
   - Просто запрашивает у INTELLECTUM **готовую структуру ГПР** для своего проекта.
   - Локальный `structure.txt` — это только **технический формат/кэш**, а не источник истины.

### Шаг 1. Загрузка сметы
- Пользователь (чаще всего ПТО) нажимает кнопку **"Загрузить смету"** в интерфейсе INTELLECTUM (веб/бот/Notion-интеграция).
- Загружает файл: `Школа_65_СМЕТА.pdf` или `.xlsx`.
